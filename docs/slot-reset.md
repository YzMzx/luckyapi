# 老虎机构建与离线回退

## 计算口径

默认 v3：樱桃 22% × 2、柠檬 5% × 3、铃铛 2.5% × 6、钻石 0.4% × 20、头奖 0.1% × 100，未中奖 70%。倍率是**含本金的总返还**。一次服务端安全随机值决定奖档，符号只展示结果；资金池在开奖前限制可接受下注，不改变赔率。

命中率是各中奖档票数之和 / 1,000,000。给定下注（分）时，结算期望返奖率是各档「票数 × 该档实际返还分数」之和 /（1,000,000 × 下注分数）。v3 使用整数倍率，因此每一个允许的下注额均为 92%；允许分数倍率的历史或自定义奖表不一定如此。管理预览的标称 RTP、会员当前注额的结算期望 RTP，以及历史实际总返还 / 总下注，不应混用。

新库默认下注范围为 $0.10–$5。指定导出库保留其管理设置的 $1–$10，使用独立不可变版本 daily-slot-v3-3000-b100-1000。旧版规则保留供历史查询；服务启动本身不会清除任何历史交易或奖励。

## 一次性回退工具

仅适用本次已审计的原始离线导出（SHA-256 6201cde9d650c1ca4bef7ef5f01249240e27eb3a432e45cf7712cd66e5dc9643），不适用于日后变化的数据。不要对运行中的 SQLite 实例操作。需要 Python 3 与能直接导入 TypeScript 的 Node。

~~~sh
python -B scripts/reset_slot_snapshot.py "path/to/luckydraw.db"          # 默认只在内存演练
python -B scripts/reset_slot_snapshot.py "path/to/luckydraw.db" --apply  # 同目录备份、验证、一次提交
~~~

先匹配每局及其玩家交易，再剔除该交易产生的正收益经验，重放其余经验事件和铭牌席位。资金按玩家逐笔重放；修正受影响的后续余额快照，保留每笔非老虎机奖励本身。最后切换新基础配置，保留管理操作历史、风险参数和基金初始入账。源文件指纹、账本或约束不匹配则拒绝；同一库不能二次回退。

**恢复方法**：关闭占用该库的服务，保留现状副本和配套日志；在单独目录将经 SHA-256 验证的原始备份复制为 luckydraw.db。不要与另一时间点的 WAL/SHM 混用。用停机维护窗口切换数据库路径；恢复会一并撤销回退后产生的新交易。仅当确认部署环境没有新交易时，才可使用本次离线产物替换部署数据库。
