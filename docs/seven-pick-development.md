# 七星寻宝：开发进度与上线门槛

现阶段是**只读预览**，不是上线版本。娱乐中心入口为 /entertainment/seven-pick，后台为 /admin/entertainment/seven-pick。不接受投注，不调度真实场次，不派奖。将后台配置设为启用也不会解除这一限制。

## 已落地

- SQLite 启动迁移、次日配置版本（北京时间）、场次物品和规则快照、Quicknet 固定轮次绑定。
- 共享模拟合约钱包、独立游戏流水；钱包与流水同事务更新，支持幂等操作，防止负余额与同时派奖/退款。合约周榜重放包含游戏现金流，但不会将其计入交易盈亏。
- 核心下注事务（仅内部测试）：单次提交全成或全败，金额精确到 0.001 模拟 USDT，每场最多五组、组合去重、安全重试；开盘锁定全站可用模拟现金的 20%，以 3,365,856 个可能结果的最大总返还为准。上限不足时开盘前跳过，异常已扣款可原路退回。
- 无偏抽样、匿名投注摘要、公开只读规则和历史接口、私有回执查询，后台支持配置版本、HTTPS 图片 URL 和风控读数。公开接口不返回锁定风控上限、用户订单或现金流水。

## 尚未接入或完成

1. 生产 Quicknet 同轮重试与签名验证、封盘持久化与 OTS 存证、完整公开证明包与独立验证工具。
2. 经合格证据触发的结算、1 小时/24 小时异常核查、追加证据与后台审核、常规异常的可续退流程，以及生产维护调度。端点故障不能自行触发退款，人工按钮也不能代替客观证据。
3. 图片上传和服务端重编码、正式下注 UI、倒计时及历史结算/退款/证明下载。
4. 生产量级性能与崩溃恢复验收。当前算法是正确性基线；在本地合成默认赔率样本中，2 / 10 / 50 / 100 种不同组合的扫描约耗时 98 / 211 / 697 / 1292 毫秒，未计 DB 与网络成本。下注会持有 SQLite 写事务；若压力测试不达标，须先做可恢复的**精确**增量风控索引，不得抽样替代。

见[公平开奖实测记录](./seven-pick-fairness-spike.md)。真实 Quicknet BLS 签名在隔离实验中验证通过；真实 OTS 日历在同一 10 分钟窗口只提供待确认回执。该结果不能证明所有场次均失败，也不能作为“承诺早于随机数”的证据。独立端到端验证和其余部署验收通过前，不得开放投注、换轮次或把待确认回执当作成功。
